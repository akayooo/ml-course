## Как запускать примеры

Локально перейди в папку `Т3. Машинное обучение`, создай окружение и установи библиотеки:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy pandas matplotlib scikit-learn
```

Код из уроков выполняй по порядку в Jupyter или Python. Пути `Данные/...` рассчитаны на запуск из этой папки. Пять синтетических учебных CSV уже лежат в `Данные/`.

Для Google Colab в первой ячейке создай папку и загрузи в неё пять CSV из `Данные/`:

```python
from pathlib import Path
from google.colab import files

folder = Path("Данные")
folder.mkdir(exist_ok=True)
for name, content in files.upload().items():
    (folder / Path(name).name).write_bytes(content)
```

После этого выполняй блоки урока сверху вниз. При перезапуске среды загрузку нужно повторить: Colab очищает локальные файлы сессии.
