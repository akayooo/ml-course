## 1.1. Что такое язык программирования?

Компьютер не понимает наши желания. Мы не можем просто сказать ему:

«Возьми данные о квартирах, обучи модель и покажи, насколько хорошо она предсказывает цены».

Эта команда выводит на экран приветствие. Здесь `print` - функция (не математическая, которую мы видели ранее, а просто какой-то набор действий программы, в нашем случае действие одно), которая выводит информацию. # Урок 2. Переменные и типы данных

Представь, что мы анализируем пользователя интернет-магазина. Мы знаем, что ему 25 лет, он совершил 7 покупок, а средний чек составляет 2500 рублей. В математических модулях мы записывали подобную информацию в вектор. Но как хранить такие данные в программе? Для этого существуют **переменные**.

## 2.1. Что такое переменная?

Переменная - это имя, с которым в программе связано определённое значение. Например:

```python
age = 25
```

Здесь мы создали переменную `age` и присвоили ей значение 25. Теперь можем использовать её в вычислениях:

```python
age = 25

print(age)  # Результат: 25
print(age + 5)  # Результат: 30
```

Важный момент: знак `=` здесь означает **присваивание**, а не математическое равенство. Мы говорим программе: свяжи имя `age` со значением 25.

## 2.2. Переменные могут хранить разные значения

```python
name = "Иван"
age = 25
purchases = 7
average_check = 2500.0
is_subscribed = True
```

Теперь разберёмся, что именно мы записали.

- `name` - текст.
- `age` - целое число.
- `purchases` - тоже целое число.
- `average_check` - число с плавающей точкой (то есть не целое).
- `is_subscribed` - логическое значение.

У каждого значения есть **тип данных**.

## 2.3. Основные типы данных

### int - целые числа

```python
age = 25
rooms = 3
```

Используется, когда мы работаем с целыми числами.

### float - числа с дробной частью

```python
price = 6.5
probability = 0.8
```

Обрати внимание: для записи дробной части в Python используется точка, а не запятая.

### str - строки

Строка - это текст. Например:

```python
name = "Анна"
city = "Москва"
```

Строки записываются в кавычках.

### bool - логический тип

Он может принимать два значения:

```python
True
False
```

```python
is_subscribed = True
has_purchased = False
```

Такие значения понадобятся для проверки условий.

### None - отсутствие значения

Иногда мы ещё не знаем значение какого-то признака. В Python для обозначения отсутствия значения можно использовать `None`.

```python
user_age = None
```

Это не то же самое, что число 0 или пустая строка.

## 2.4. Как узнать тип данных?

Используем функцию `type()`.

```python
age = 25
price = 6.5
name = "Иван"

print(type(age))
print(type(price))
print(type(name))
```

Python сообщит, что мы работаем с `int`, `float` и `str`.

## 2.5. Можно ли менять значение переменной?

Да. Например, увеличим число покупок на единицу:

```python
purchases = 7

purchases = purchases + 1

print(purchases)   # Результат: 8
```

Что произошло? Сначала покупок было 7. Затем мы взяли текущее значение, прибавили 1 и присвоили результат той же переменной. Есть и более короткая запись:

```python
purchases += 1
```

Она означает то же самое.

## 2.6. Почему это важно для ML?

Вспомним нашу модель оценки квартир. У неё есть признаки:

- площадь;
- количество комнат;
- этаж;
- расстояние до метро.

Все эти характеристики можно хранить в переменных. Например:

```python
area = 40
rooms = 1
floor = 5
distance_to_metro = 800
```

Пока это данные одной квартиры. Но позднее мы научимся хранить тысячи таких объектов и передавать их ML-моделям.

# Урок 3. Арифметика, сравнения и логические операции

Теперь мы умеем хранить данные. Но программа должна не только запоминать числа. Она должна уметь с ними работать. Например, рассчитывать средний чек, прибыль магазина или ошибку ML-модели. Начнём с обычной арифметики.

## 3.1. Основные арифметические операции

В Python есть знакомые нам операции:

```python
print(10 + 3)   # Сложение: 13
print(10 - 3)   # Вычитание: 7
print(10 * 3)   # Умножение: 30
print(10 / 4)   # Деление: 2.5
```

Но есть ещё несколько полезных операторов.

### Целочисленное деление

```python
print(10 // 3)  # Результат: 3
```

Оператор `//` выполняет деление с округлением результата вниз до целого значения. Для положительных чисел это похоже на отбрасывание дробной части.

### Остаток от деления

```python
print(10 % 3)  # Результат: 1
```

Этот оператор позволяет, например, проверять чётность числа.

### Возведение в степень

```python
print(2 ** 3)  # Результат: 8
```

Именно `**`, а не `^`, используется в Python для возведения в степень. Это понадобится при вычислении квадратов ошибок модели.

## 3.2. Порядок вычислений

Python учитывает математический порядок операций. Например:

```python
print(2 + 3 * 4)  # Результат: 14
```

Если сначала нужно выполнить сложение, используем скобки:

```python
print((2 + 3) * 4)  # Результат: 20
```

## 3.3. Рассчитаем выручку магазина

Допустим, пользователь совершил 7 покупок со средним чеком 2500 рублей.

```python
purchases = 7
average_check = 2500

revenue = purchases * average_check

print(revenue)  # Результат: 17500
```

Это пример простого вычисления на основе нескольких признаков.

## 3.4. Операторы сравнения

А теперь представь, что мы хотим проверить, совершил ли пользователь больше пяти покупок. Для этого существуют операторы сравнения.

```python
print(7 > 5)    # True
print(7 < 5)    # False
print(7 == 5)   # False
print(7 != 5)   # True
print(7 >= 5)   # True
print(7 <= 5)   # False
```

Обрати внимание на два разных обозначения:

`=` - присваивание.
`==` - сравнение на равенство.

Начинающие программисты часто их путают.

## 3.5. Логические операции

Иногда нам нужно проверить сразу несколько условий. Например, пользователь совершил больше пяти покупок **и** подписан на рассылку. В Python для этого используется `and`.

```python
purchases = 7
is_subscribed = True

print(purchases > 5 and is_subscribed)  # Результат: True
```

Если достаточно выполнения хотя бы одного из условий, используется `or`.

```python
print(purchases > 10 or is_subscribed)  # Результат: True
```

Также существует `not`, который меняет логическое значение на противоположное.

```python
print(not True)  # Результат: False
```

## 3.6. Зачем это в ML?

В анализе данных нам постоянно приходится проверять условия. Например:

- площадь квартиры больше 50 м²;
- количество покупок равно нулю;
- вероятность мошенничества выше установленного порога;
- значение признака отсутствует.

Позднее такие проверки понадобятся для фильтрации данных, оценки прогнозов и обработки результатов моделей.

# Урок 4. Строки и ввод данных

До этого все значения мы прописывали прямо в коде. Но представь программу, которая каждый раз рассчитывает цену квартиры. Неужели нам придётся постоянно открывать код и менять площадь вручную? Конечно, нет. Мы можем попросить пользователя ввести значение.

## 4.1. Работа со строками

Строки - это текстовые данные. Например:

```python
name = "Алексей"

print(name)
```

Строки можно соединять:

```python
first_name = "Алексей"
last_name = "Иванов"

full_name = first_name + " " + last_name

print(full_name)  # Результат: Алексей Иванов
```

## 4.2. Форматирование строк

В Python есть очень удобный инструмент - f-строки. Например:

```python
name = "Алексей"
age = 25

print(f"Пользователь {name}, возраст: {age}")  # Результат: Пользователь Алексей, возраст: 25
```

С помощью фигурных скобок мы вставляем значения переменных прямо в текст. В дальнейшем это будет очень удобно при выводе результатов ML-моделей.

## 4.3. Ввод данных

Для ввода информации используется функция `input()`.

```python
name = input("Как тебя зовут? ")

print(f"Привет, {name}!")
```

Программа попросит ввести имя. После этого использует введённое значение.

## 4.4. Важная особенность input

Функция `input()` возвращает строку. Даже если пользователь ввёл число. Например:

```python
age = input("Сколько тебе лет? ")
```

Переменная `age` будет иметь тип `str`. Поэтому если мы хотим выполнять математические операции, значение нужно преобразовать. Для целого числа:

```python
age = int(input("Сколько тебе лет? "))
```

Для дробного:

```python
price = float(input("Введите цену: "))
```

Теперь Python воспринимает введённые значения как числа. Если пользователь введёт текст вместо числа, произойдёт ошибка. Позже мы научимся её обрабатывать.

## 4.5. Создадим первый калькулятор стоимости квартиры

Используем простую формулу из математического модуля:

`ŷ = 0.12 × площадь + 0.5 × комнаты + 1`

Цена измеряется в миллионах рублей.

```python
area = float(input("Площадь квартиры: "))
rooms = int(input("Количество комнат: "))

price = 0.12 * area + 0.5 * rooms + 1

print(f"Прогноз стоимости: {price:.2f} млн ₽")
```

Обрати внимание на запись:

`{price:.2f}`

Она позволяет вывести число с двумя знаками после десятичной точки. Например, для площади 40 м² и одной комнаты получим прогноз:

`6.30 млн ₽`

Коэффициенты в этой формуле пока заданы вручную. Поэтому мы ещё не обучили настоящую ML-модель. Но уже написали программу, которая выполняет математический прогноз.

## 4.6. Полезные операции со строками

```python
city = "  МОСКВА  "

print(city.strip())
print(city.lower())
```

`strip()` убирает пробелы по краям.
`lower()` преобразует буквы в нижний регистр.

Это простые, но полезные операции при подготовке текстовых данных.

# Урок 5. Условия: if, elif и else

Представь, что мы хотим автоматически определять заинтересованность пользователя интернет-магазина. Если человек посещает сайт каждый день и добавляет товары в корзину, мы можем считать его потенциально заинтересованным покупателем. Если пользователь зашёл один раз и ничего не посмотрел - ситуация другая. Как научить программу принимать решения? Для этого используются условия.

## 5.1. Оператор if

В Python условие записывается с помощью `if`. Например:

```python
age = 20

if age >= 18:
    print("Пользователь совершеннолетний")
```

Программа проверяет условие. Если оно истинно, выполняет код внутри блока.

## 5.2. Почему важны отступы?

Обрати внимание, что строка `print` находится правее строки `if`. Это не случайность. **В Python отступы определяют, какие строки относятся к одному блоку кода.** Обычно используют четыре пробела. То есть табуляцию. Например:

```python
age = 20

if age >= 18:
    print("Доступ разрешён")
    print("Проверка завершена")
```

Обе строки `print` относятся к условию.

## 5.3. Что такое else?

Иногда нам нужно выполнить альтернативное действие.

```python
age = 16

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Если условие не выполняется, программа переходит в блок `else`.

## 5.4. Несколько условий: elif

Представим, что мы хотим разделить пользователей на группы.

```python
purchases = 7

if purchases >= 10:
    print("Очень активный покупатель")
elif purchases >= 5:
    print("Активный покупатель")
else:
    print("Новый или редкий покупатель")
```

Программа проверяет условия сверху вниз. Как только находит первое истинное условие, выполняет соответствующий блок и пропускает остальные ветки этой конструкции.

## 5.5. Комбинируем условия

Представим, что нас интересуют пользователи, которые часто посещают магазин и уже добавили товары в корзину.

```python
visits = 8
cart_items = 2

if visits >= 5 and cart_items > 0:
    print("Высокий интерес к покупке")
elif visits >= 5:
    print("Часто посещает сайт, но корзина пуста")
else:
    print("Пока мало признаков интереса")
```

Здесь используется логическая операция `and`. Мы проверяем сразу два условия.

## 5.6. А это уже машинное обучение?

Нет. И здесь очень важно почувствовать разницу. В нашем примере мы сами придумали правила. Например:

«Если посещений больше пяти и в корзине есть товар, считаем интерес высоким».

Это обычное программирование. А в машинном обучении мы можем показать алгоритму данные о тысячах пользователей и научить его находить закономерности, которые помогают предсказывать покупки. Правила модели будут определяться обучением на данных, а не только придуманными вручную порогами.

# Урок 6. Циклы — как заставить компьютер повторять действия

Представь, что у нас есть сто пользователей, и мы хотим вывести информацию о каждом. Можно написать сто отдельных команд `print`. Но это было бы очень неудобно. А если пользователей миллион? Очевидно, нужен механизм, который позволит повторять одни и те же действия автоматически. Такой механизм называется **циклом**.

## 6.1. Цикл for

Самый простой пример:

```python
for number in range(1, 6):
    print(number)  # Вывод по строкам: 1, 2, 3, 4, 5
```

Разберём, что произошло. `range(1, 6)` задаёт последовательность чисел от 1 до 5. Правая граница не включается. `for` последовательно берёт очередное значение и присваивает его переменной `number`. Затем выполняет код внутри цикла.

## 6.2. Цикл выполняет действие много раз

```python
for i in range(3):
    print("Я изучаю Python!")  # Результат: «Я изучаю Python!» три раза
```

Обрати внимание: `range(3)` даёт значения 0, 1 и 2. То есть три числа.

## 6.3. Считаем сумму чисел

Представим, что нам нужно сложить числа от 1 до 5.

```python
total = 0

for number in range(1, 6):
    total = total + number

print(total)  # Результат: 15
```

Посмотрим, как изменялась переменная:

|Число|Сумма после прибавления|
|---|---|
|1|1|
|2|3|
|3|6|
|4|10|
|5|15|

Компьютер последовательно повторил одну и ту же операцию.

## 6.4. Цикл while

Существует ещё один вид цикла - `while`. Он повторяет действия, пока выполняется определённое условие. Например:

```python
counter = 3

while counter > 0:
    print(counter)  # Вывод по строкам: 3, 2, 1
    counter -= 1

print("Готово!")  # Результат: Готово!
```

Здесь программа повторяет действия, пока `counter` больше нуля. Важно следить, чтобы условие когда-нибудь перестало выполняться. Иначе может возникнуть бесконечный цикл.

## 6.5. Чем for отличается от while?

На начальном этапе можно запомнить так:

- `for` удобно использовать, когда мы перебираем определённую последовательность значений.
- `while` удобно использовать, когда повторение зависит от условия.

Например, пока пользователь не ввёл корректное значение.

## 6.6. Зачем циклы нужны в ML?

Представим, что у нас есть данные о тысяче квартир. Для каждой нужно:

1. Получить признаки.
2. Рассчитать прогноз цены.
3. Сравнить прогноз с реальной ценой.
4. Сохранить ошибку.

Цикл позволяет выполнить эти действия для всех объектов. Именно этим мы займёмся в конце модуля.

# Урок 7. Списки и кортежи — храним множество значений

До этого мы сохраняли в переменную одно число. Например:

```python
price = 6.0
```

Но представь, что у нас есть настоящие цены тысячи квартир. Создавать тысячу отдельных переменных было бы неудобно. Поэтому в Python существуют специальные структуры данных. Начнём со списков.

## 7.1. Что такое список?

Список - это упорядоченная изменяемая коллекция элементов. Например:

```python
prices = [6.0, 9.0, 12.0]
```

Мы сохранили цены трёх квартир в одной переменной. Теперь можем обращаться к отдельным элементам.

## 7.2. Индексы

В Python индексация начинается с нуля.

```python
prices = [6.0, 9.0, 12.0]

print(prices[0])  # Результат: 6.0
print(prices[1])  # Результат: 9.0
print(prices[2])  # Результат: 12.0
```

Первый элемент имеет индекс 0. Второй - индекс 1. Третий - индекс 2. Это очень важно запомнить.

## 7.3. Последний элемент списка

Чтобы получить последний элемент, можно использовать индекс `-1`.

```python
print(prices[-1])  # Результат: 12.0
```

## 7.4. Длина списка

Функция `len()` показывает количество элементов.

```python
print(len(prices))  # Результат: 3
```

## 7.5. Добавление элементов

Чтобы добавить новый элемент, используется `append()`.

```python
prices = [6.0, 9.0, 12.0]

prices.append(10.0)

print(prices)  # Результат: [6.0, 9.0, 12.0, 10.0]
```

Список изменился.

## 7.6. Вычисления со списками

А теперь вспомним статистику из М2. Допустим, нам нужно найти среднюю стоимость квартир.

```python
prices = [6.0, 9.0, 12.0]

average_price = sum(prices) / len(prices)

print(average_price)  # Результат: 9.0
```

Мы использовали:

- `sum()` - сумму элементов;
- `len()` - количество элементов.

И получили среднее арифметическое. То, что раньше мы считали вручную, теперь вычисляется одной строкой.

## 7.7. Перебор списка

Списки прекрасно работают с циклами.

```python
prices = [6.0, 9.0, 12.0]

for price in prices:
    print(f"Стоимость квартиры: {price} млн ₽")
```

Программа последовательно перебирает все элементы.

## 7.8. Срезы

Иногда нам нужна только часть списка.

```python
prices = [6.0, 9.0, 12.0, 10.0]

print(prices[1:3])  # Результат: [9.0, 12.0]
```

Срез `1:3` включает элементы с индексами 1 и 2. Правая граница, как и в `range`, не включается.

## 7.9. Кортежи

Кроме списков, в Python есть кортежи - `tuple`. Например:

```python
coordinates = (3, 2)
```

Кортеж похож на список, но его элементы нельзя менять обычным присваиванием по индексу. Список удобен для изменяемого набора данных. Кортеж - для фиксированной последовательности значений. Например, он может использоваться для хранения координат или размеров.

## 7.10. Список и вектор — одно и то же?

Не совсем. Список - это структура данных Python. А вектор - математический объект. Мы можем представить вектор с помощью списка, например:

```python
vector = [3, 2]
```

Но обычные списки Python не поддерживают все привычные векторные операции в математическом смысле. Например:

```python
[1, 2] + [3, 4]
```

даст:

`[1, 2, 3, 4]`

То есть списки соединятся, а не сложатся поэлементно. Для удобной математической работы с векторами и матрицами мы позже будем использовать NumPy.

# Урок 8. Словари и множества — структурируем данные

Мы научились хранить цены нескольких квартир в списке. Но каждая квартира имеет не только цену. У неё есть площадь, количество комнат, этаж и другие характеристики. Как объединить всё это в одном объекте? Один из вариантов - использовать словарь.

## 8.1. Что такое словарь?

Словарь, или `dict`, хранит пары:

**ключ → значение**

```python
apartment = {
    "area": 40,
    "rooms": 1,
    "price": 6.0
}
```

Здесь:

- `"area"` - ключ, связанный с площадью;
- `"rooms"` - ключ, связанный с количеством комнат;
- `"price"` - ключ, связанный с ценой.

Чтобы получить значение, обращаемся к соответствующему ключу:

```python
print(apartment["area"])  # Результат: 40
print(apartment["price"])  # Результат: 6.0
```

## 8.2. Изменение значения

Словарь можно изменять.

```python
apartment["price"] = 6.5
```

Теперь цена квартиры равна 6.5 миллиона рублей. Также можно добавлять новые ключи:

```python
apartment["floor"] = 5
```

## 8.3. Список словарей

А теперь сделаем самое полезное. Представим три квартиры:

```python
apartments = [
    {"area": 40, "rooms": 1, "price": 6.0},
    {"area": 60, "rooms": 2, "price": 9.0},
    {"area": 80, "rooms": 3, "price": 12.0}
]
```

Здесь:

- внешний список хранит все квартиры;
- каждый словарь хранит характеристики одной квартиры.

Получается структура, очень похожая на таблицу. Давай выведем информацию о каждой квартире:

```python
for apartment in apartments:
    print(apartment["area"], apartment["rooms"])  # Вывод по строкам: 40 1, 60 2, 80 3
```

## 8.4. Что такое множества?

В Python есть ещё один полезный тип коллекций - `set`. Он хранит уникальные элементы. Например:

```python
cities = ["Москва", "Казань", "Москва", "Томск"]

unique_cities = set(cities)

print(len(unique_cities))  # Результат: 3
```

Потому что уникальных городов три. Множества также позволяют проверять принадлежность элемента и выполнять операции пересечения и объединения. Но на этом этапе нам достаточно запомнить их основное назначение: **работа с уникальными значениями**.

## 8.5. Как это пригодится в анализе данных?

Представь, что у нас есть таблица пользователей. Каждый пользователь имеет:

- возраст;
- город;
- количество покупок;
- средний чек.

Мы можем представить отдельного пользователя словарём. А всю таблицу - списком словарей. Позже pandas позволит работать с такими данными гораздо удобнее. Но сейчас важно понять саму структуру информации.

# Урок 9. Функции — учимся писать понятный код

Представь, что мы написали формулу прогноза цены квартиры. Теперь хотим применить её к ста разным квартирам. Можно каждый раз копировать одну и ту же строку. Но профессиональные разработчики стараются избегать повторения одинакового кода. Для этого используются функции.

## 9.1. Что такое функция?

Функция - это именованный блок кода, который можно вызывать многократно. Например:

```python
def say_hello():
    print("Привет!")
```

Мы создали функцию с названием `say_hello`. Чтобы её выполнить, нужно вызвать:

```python
say_hello()
```

## 9.2. Функция с параметром

А теперь пусть функция приветствует конкретного человека.

```python
def say_hello(name):
    print(f"Привет, {name}!")
```

Вызываем:

```python
say_hello("Анна")  # Результат: Привет, Анна!
say_hello("Иван")  # Результат: Привет, Иван!
```

`name` - параметр функции. При вызове мы передаём ему конкретное значение - аргумент.

## 9.3. Что такое return?

До этого функция только выводила текст. Но часто нам нужно получить результат вычисления и использовать его в другой части программы. Для этого существует `return`. Например:

```python
def add_numbers(a, b):
    return a + b

result = add_numbers(3, 5)

print(result)  # Результат: 8
```

Здесь функция возвращает сумму. Это важное отличие от `print`. `print()` показывает информацию на экране. `return` возвращает значение из функции, чтобы программа могла использовать его дальше.

## 9.4. Функция прогноза стоимости квартиры

Теперь напишем уже знакомую формулу. Будем измерять площадь в десятках квадратных метров.

```python
def predict_price(area_tens, rooms):
    price = 1.2 * area_tens + 0.5 * rooms + 1
    return price
```

Проверим её работу.

```python
print(predict_price(4, 1))  # Результат: 6.3
print(predict_price(6, 2))  # Результат: 9.2
print(predict_price(8, 3))  # Результат: 12.1
```

Мы получили три знакомых прогноза из модуля линейной алгебры. Но теперь это настоящая функция на Python.

## 9.5. Почему функции так важны?

Представим, что мы решили изменить формулу прогноза. Например, добавить новый признак - этаж. Без функций пришлось бы искать и исправлять все места, где мы вручную рассчитывали цену. А с функцией достаточно изменить её определение и соответствующие вызовы. Кроме того, функции:

- уменьшают повторение кода;
- позволяют разбивать большие задачи на маленькие;
- делают программу более понятной;
- облегчают проверку и исправление ошибок.

## 9.6. Чистые и понятные функции

На начальном этапе старайся придерживаться простого правила.

**Одна функция - одна понятная задача.**

Например: `calculate_average()` - рассчитывает среднее. `predict_price()` - прогнозирует стоимость. `calculate_mse()` - вычисляет среднеквадратичную ошибку. С такими названиями код легче читать и понимать.

# Урок 10. Ошибки в Python — почему код не работает и что делать?

Итак, мы научились писать первые программы. Но я должен предупредить тебя об одной вещи.

**Ты будешь постоянно сталкиваться с ошибками.**

Причём не только сейчас, когда учишься программировать. С ними регулярно работают и разработчики с многолетним опытом. Важен не сам факт появления ошибки, а то, насколько быстро ты умеешь разобраться в её причине.

## 10.1. Синтаксические ошибки

Представь, что мы забыли двоеточие после `if`.

```python
age = 20

if age >= 18
    print("OK")
```

Python не сможет выполнить такую программу. Он сообщит об ошибке `SyntaxError`. Это означает, что код написан с нарушением синтаксиса языка.

## 10.2. NameError

```python
price = 100

print(prcie)
```

Мы случайно написали `prcie` вместо `price`. Python сообщит, что такого имени не существует. Это ошибка `NameError`.

## 10.3. TypeError

```python
age = "25"

print(age + 5)
```

Здесь мы пытаемся сложить текст и число. Python не знает, какую операцию мы хотим выполнить в таком случае. Поэтому получаем `TypeError`. Решение:

```python
age = int(age)

print(age + 5)
```

Теперь всё работает.

## 10.4. IndexError

Ещё одна распространённая ошибка:

```python
prices = [6.0, 9.0, 12.0]

print(prices[5])
```

В списке всего три элемента. Их индексы: 0, 1 и 2. Элемента с индексом 5 нет. Поэтому возникает `IndexError`.

## 10.5. ValueError

```python
age = int("двадцать пять")
```

Python не может преобразовать такую строку в число стандартным способом. Поэтому возникает `ValueError`.

## 10.6. Как обрабатывать ошибки?

Иногда мы заранее понимаем, что пользователь может ввести неправильные данные. Например, вместо площади квартиры написать слово. Для таких ситуаций существует конструкция `try` / `except`.

```python
try:
    area = float(input("Введите площадь: "))

    if area > 0:
        print(f"Площадь: {area}")
    else:
        print("Площадь должна быть положительной")

except ValueError:
    print("Нужно ввести число, например 40")
```

Программа пытается выполнить код внутри `try`. Если возникает ошибка преобразования значения, выполняется блок `except ValueError`. Это позволяет обработать ожидаемую проблему без аварийного завершения программы.

## 10.7. Как правильно искать ошибки?

Иди по шагам:

1. Прочитай сообщение об ошибке и найди строку, на которой она возникла.
2. Проверь значения и типы переменных с помощью `print()` и `type()`.
3. Попробуй воспроизвести проблему на коротком примере.
4. Исправь причину и снова запусти программу.

Не нужно сразу переписывать весь код: обычно сообщение об ошибке уже подсказывает, где искать.

## 10.8. А можно пользоваться ChatGPT?

Конечно. Можно показать ИИ сообщение об ошибке и попросить объяснить, что оно означает. Но есть важное правило.

**Не ограничивайся слепым копированием исправленного кода.**

Постарайся понять:

- почему ошибка возникла;
- какой именно код её исправил;
- что произойдёт, если ошибка повторится.

Так ты действительно научишься программировать, а не просто пользоваться готовыми ответами.

# Урок 11. Модули, библиотеки и работа с файлами

До этого мы писали весь код самостоятельно. Но представь, что для каждой задачи нам пришлось бы с нуля реализовывать все математические операции, работу с файлами и обработку таблиц. На это уходило бы огромное количество времени. Поэтому в Python существуют модули и библиотеки.

## 11.1. Что такое модуль?

Модуль - это файл с Python-кодом, который можно использовать в других программах. Python поставляется с большой стандартной библиотекой. Например, существует модуль `math`. Он содержит математические функции.

```python
import math

print(math.sqrt(25))  # Результат: 5.0
```

`math.sqrt()` вычисляет квадратный корень. Мы не писали алгоритм извлечения квадратного корня самостоятельно. Мы использовали готовую функцию.

## 11.2. Что такое библиотека?

Библиотекой часто называют набор готовых инструментов для определённой задачи. Например, **NumPy** помогает считать с массивами и матрицами, **pandas** - анализировать таблицы, а **Matplotlib** - строить графики. Позже познакомимся с **scikit-learn** для классического ML и **PyTorch** для нейросетей. Пока главное понять принцип: **мы можем использовать готовые инструменты, не реализуя всё с нуля**.

## 11.3. Что такое CSV?

В машинном обучении мы очень часто работаем с табличными данными. Например, у нас есть таблица:

|area|rooms|price|
|---|---|---|
|40|1|6.0|
|60|2|9.0|
|80|3|12.0|

Такие данные можно хранить в CSV-файле. CSV - это обычный текстовый формат для хранения таблиц. Например, содержимое файла может выглядеть так:

```csv
area,rooms,price
40,1,6.0
60,2,9.0
80,3,12.0
```

Первая строка содержит названия столбцов. Следующие строки - данные отдельных квартир.

## 11.4. Создадим CSV-файл

В Python можно работать с файлами с помощью `open()`. Для примера создадим свой небольшой CSV.

```python
with open("apartments.csv", "w", encoding="utf-8") as file:
    file.write("area,rooms,price\n")
    file.write("40,1,6.0\n")
    file.write("60,2,9.0\n")
    file.write("80,3,12.0\n")
```

Мы создали файл `apartments.csv` и записали в него несколько строк. `"w"` означает режим записи. Если файл с таким именем уже существует, этот режим перезапишет его содержимое. `with` помогает корректно закрыть файл после окончания работы. А `\n` обозначает переход на новую строку.

## 11.5. Читаем данные

Теперь можем использовать стандартный модуль `csv`.

```python
import csv

with open("apartments.csv", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row)
```

`DictReader` позволяет читать строки таблицы как словари, где ключами являются названия столбцов. Обрати внимание: значения из CSV обычно читаются как строки. Если нам нужно число, его придётся преобразовать. Например:

```python
import csv

with open("apartments.csv", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)

    for row in reader:
        area = int(row["area"])
        price = float(row["price"])

        print(f"Площадь: {area} м², цена: {price} млн ₽")
```

Получим информацию о трёх квартирах.

## 11.6. Почему в ML всё будет немного проще?

Чтение данных вручную через `csv` полезно для понимания механизма. Но представь, что у нас таблица с миллионом строк и сотней столбцов. Постоянно работать с ней через списки и словари было бы неудобно. Поэтому для анализа данных мы будем использовать специальную библиотеку - pandas. Она позволит читать таблицы, фильтровать строки, рассчитывать статистики и выполнять множество других операций гораздо удобнее.

# Урок 12. Первый мини-проект: прогнозируем стоимость квартир на Python

Ну что, теперь пришло время объединить всё, что мы изучили. У нас уже есть практически все необходимые инструменты. Мы умеем:

- создавать переменные;
- работать с числами;
- хранить данные в списках и словарях;
- писать функции;
- использовать циклы;
- выполнять математические вычисления.

И сейчас мы напишем первую маленькую программу, очень похожую на основу настоящего ML-проекта.

**Мы будем прогнозировать стоимость квартир и вычислять ошибку нашей модели.**

## 12.1. Подготовим данные

Возьмём три квартиры. Для каждой будем хранить:

- площадь в десятках квадратных метров;
- количество комнат;
- настоящую стоимость в миллионах рублей.

```python
apartments = [
    {"area_tens": 4, "rooms": 1, "real_price": 6.0},
    {"area_tens": 6, "rooms": 2, "real_price": 9.0},
    {"area_tens": 8, "rooms": 3, "real_price": 12.0}
]
```

Обрати внимание: это список словарей. Каждый словарь - отдельная квартира.

## 12.2. Создадим функцию прогноза

Используем знакомую формулу:

`ŷ = 1.2 × площадь + 0.5 × комнаты + 1`

```python
def predict_price(area_tens, rooms):
    prediction = 1.2 * area_tens + 0.5 * rooms + 1
    return prediction
```

Мы создали функцию, которая принимает два признака и возвращает прогноз стоимости.

## 12.3. Пройдём по всем квартирам

Теперь используем цикл.

```python
for apartment in apartments:
    prediction = predict_price(
        apartment["area_tens"],
        apartment["rooms"]
    )

    print(prediction)  # Вывод по строкам: 6.3, 9.2, 12.1
```

Получили прогнозы сразу для всех трёх квартир.

## 12.4. Посчитаем ошибку

Вспомним среднеквадратичную ошибку:

`MSE = среднее квадратов ошибок`

Для этого нам нужно:

1. Получить прогноз каждой квартиры.
2. Вычесть настоящую цену.
3. Возвести разницу в квадрат.
4. Сложить квадраты ошибок.
5. Разделить сумму на количество квартир.

Сначала создадим пустой список:

```python
squared_errors = []
```

Затем для каждой квартиры рассчитаем квадрат ошибки и сохраним результат.

```python
for apartment in apartments:
    prediction = predict_price(
        apartment["area_tens"],
        apartment["rooms"]
    )

    real_price = apartment["real_price"]
    error = prediction - real_price
    squared_error = error ** 2

    squared_errors.append(squared_error)
```

Теперь в списке `squared_errors` хранятся квадраты ошибок нашей модели.

## 12.5. Найдём MSE

```python
mse = sum(squared_errors) / len(squared_errors)

print(mse)  # Примерно: 0.0466666667
```

Если хотим вывести результат более аккуратно:

```python
print(round(mse, 4))  # Результат: 0.0467
```

Это та же самая ошибка, которую мы раньше рассчитывали вручную. Но теперь Python выполнил вычисления за нас.

## 12.6. Полный код проекта

Давай соберём всё в одну программу.

```python
# Данные о квартирах
apartments = [
    {"area_tens": 4, "rooms": 1, "real_price": 6.0},
    {"area_tens": 6, "rooms": 2, "real_price": 9.0},
    {"area_tens": 8, "rooms": 3, "real_price": 12.0}
]

# Функция прогноза
def predict_price(area_tens, rooms):
    return 1.2 * area_tens + 0.5 * rooms + 1

# Список для квадратов ошибок
squared_errors = []

# Прогнозируем стоимость каждой квартиры
for apartment in apartments:

    prediction = predict_price(
        apartment["area_tens"],
        apartment["rooms"]
    )

    real_price = apartment["real_price"]

    error = prediction - real_price
    squared_errors.append(error ** 2)

    print(
        f"Прогноз: {prediction:.1f} млн ₽, "
        f"реальная цена: {real_price:.1f} млн ₽"
    )  # Вывод по строкам: 6.3/6.0, 9.2/9.0, 12.1/12.0 млн ₽

# Рассчитываем среднеквадратичную ошибку
mse = sum(squared_errors) / len(squared_errors)

print(f"MSE модели: {mse:.4f}")  # Результат: MSE модели: 0.0467
```

Запусти блок целиком в новой ячейке Colab или сохрани его в `apartments.py` и выполни `python3 apartments.py`. Результат должен быть таким:

```text
Прогноз: 6.3 млн ₽, реальная цена: 6.0 млн ₽
Прогноз: 9.2 млн ₽, реальная цена: 9.0 млн ₽
Прогноз: 12.1 млн ₽, реальная цена: 12.0 млн ₽
MSE модели: 0.0467
```

Если числа отличаются, проверь площади в десятках квадратных метров, веса и формулу ошибки. Код не скачивает данные и работает без дополнительных библиотек.

## 12.7. Это уже машинное обучение?

**Пока мы не обучили настоящую ML-модель:** веса `1.2`, `0.5` и свободный коэффициент `1` заданы вручную. Программа рассчитывает прогнозы по готовой формуле, но не подбирает параметры на основании данных. Настоящий алгоритм обучения должен был бы:

1. Получить данные о квартирах.
2. Начать с некоторых значений параметров.
3. Рассчитать прогнозы.
4. Вычислить функцию потерь.
5. Изменить параметры, чтобы попытаться уменьшить ошибку.
6. Повторять процесс.

Этот механизм мы изучали в М3. Позже алгоритмы и библиотеки будут выполнять такие шаги автоматически. А пока ты уже написал важную часть будущего ML-проекта: **данные → прогноз → сравнение с правильным ответом → вычисление ошибки**. Для первого блока программирования это хороший результат.
