## Как запустить примеры

Открой терминал в папке `Т4. Глубокое обучение`. Установи Python 3.11 или новее, затем зависимости:

```bash
python -m pip install torch torchvision pandas scikit-learn pillow numpy
```

Запусти любой пример:

```bash
python Примеры/m12_train_mlp.py --epochs 30
python Примеры/m13_train_cnn.py --epochs 25
python Примеры/m14_text_baseline.py
```

Скрипты печатают метрики обучения и проверки, выбирают настройки по validation и показывают итог на test. При проверочном запуске с указанными выше параметрами MLP получила test AP 0.481 против 0.499 у логистической регрессии, CNN получила test accuracy 0.840, текстовый baseline получил test F1 1.000. Это результаты на маленьких искусственных наборах, а не оценка качества на реальных данных. Для изучения формул и отдельных операций запускай блоки кода из уроков последовательно. Разделы с предобученными моделями могут потребовать скачивания весов из интернета.
