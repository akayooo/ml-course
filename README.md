# Машинное обучение: как вкатиться в IT с нуля

Курс по машинному обучению с постепенным переходом от математики и Python к моделям, нейросетям и поиску работы.

Начни с [введения](Введение.md), затем проходи темы по порядку. Внутри каждой темы модули идут по номерам.

| Тема | Что внутри | Состояние |
| --- | --- | --- |
| [Т1. Математика](Т1.%20Математика/README.md) | Линейная алгебра, вероятность и статистика, анализ и оптимизация | М1–М3 готовы |
| [Т2. Программирование](Т2.%20Программирование/README.md) | Python и инструменты для работы с данными | М4–М5 в планах |
| [Т3. Машинное обучение](Т3.%20Машинное%20обучение/README.md) | Классическое ML, оценка моделей и другие задачи | М6–М8 в планах |
| [Т4. Глубокое обучение](Т4.%20Глубокое%20обучение/README.md) | Нейросети, компьютерное зрение, NLP и LLM | М9–М11 в планах |
| [Т5. Собеседование](Т5.%20Собеседование/README.md) | MLOps, проектирование ML-систем, портфолио и выход на работу | М12–М16 в планах |

Файлы модулей М4–М16 пока пустые: их названия показывают план курса.
