## Как запустить сервис М15 и спринт М17

Открой терминал в папке `Т5. Собеседование`. Нужен Python 3.11 или новее.

```bash
python -m pip install -r requirements.txt
python Примеры/generate_datasets.py
python Примеры/m15_train.py
python -m pytest -q Примеры/test_m15_api.py
python Примеры/m15_monitor.py
python -m uvicorn m15_api:app --app-dir Примеры --host 127.0.0.1 --port 8000
```

После запуска сервера открой `http://127.0.0.1:8000/docs` и выполни запрос к `/predict`. Последняя команда держит сервер запущенным; останови его через `Ctrl+C`. Проверочный запуск: обучение разделило 1500 записей на 900 train, 300 validation и 300 test; итоговая ROC-AUC 0,612 и average precision 0,445. Мониторинг показал сдвиг `visits_7d` (PSI 0,850). Пять API-тестов прошли. Эти числа относятся только к искусственным данным. Модель сохраняется локально в `Примеры/model/` и не попадает в Git.
