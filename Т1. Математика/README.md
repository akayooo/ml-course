# Т1. Математика

Математическая база для машинного обучения. Проходи модули по порядку: идеи из предыдущих понадобятся в следующих.

1. [М1. Линейная алгебра для ML](M1.%20Линейная%20алгебра%20для%20ML.md) — векторы, матрицы, расстояния и преобразования.
2. [М2. Вероятность и статистика](M2.%20Вероятность%20и%20статистика.md) — вероятности, распределения, выборки и проверка гипотез.
3. [М3. Анализ и оптимизация](M3.%20Анализ%20и%20оптимизация.md) — производные, функция потерь и градиентный спуск.

Все три модуля содержат уроки и практические задания.
